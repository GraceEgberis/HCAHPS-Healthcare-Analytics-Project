🏥 HCAHPS Healthcare Data Analytics Project

National Patient Experience, Hospital Performance & Survey Response Analysis (2015–2023)

📌 Project Overview

This project analyses Hospital Consumer Assessment of Healthcare Providers and Systems (HCAHPS) data to examine patient experience, hospital performance, and survey participation across the United States from 2015 to 2023.

The project uses SQL Server Management Studio (SSMS) for data cleaning and Microsoft Excel 2019 for data analysis, visualization, and interactive dashboard development.

The objective is to transform healthcare survey data into meaningful insights that support understanding of patient experience trends, state-level performance, and hospital survey participation.

🎯 Project Objectives

- Evaluate national patient experience trends from 2015 to 2023.
- Examine changes in hospital performance across different HCAHPS measures.
- Identify states with the highest and lowest patient experience ratings.
- Analyse hospital participation and survey completion.
- Evaluate annual survey response rates.
- Present findings through interactive Excel dashboards.

🛠️ Tools & Technologies

- SQL Server Management Studio (SSMS): Data cleaning, validation, and preparation.
- Microsoft Excel 2019: Data analysis, PivotTables, PivotCharts, formulas, and dashboard development.

🗂️ Project Dataset

The project dataset contains information relating to:

- National HCAHPS results.
- State-level HCAHPS results.
- Hospital survey responses.
- Survey questions and measures.
- Reporting periods.
- State information.

The analysis covers nine annual reporting periods (2015–2023).

🧹 Data Cleaning & Preparation

Data preparation was carried out using SQL Server Management Studio.

Key activities included:

- Examining table structures and relationships.
- Checking for duplicate records.
- Identifying missing and invalid values.
- Validating percentage fields.
- Reviewing primary and foreign key relationships.
- Converting reporting date fields into appropriate date formats.
- Preparing datasets for analysis in Excel.

Data validation was performed to ensure consistency and reliability before dashboard development.

🔍 Key Findings & Insights

National Patient Experience

- The national top-box score increased from 71.0% in 2015 to 72.3% in 2021.
- A decline followed, with the top-box score reaching 69.4% in 2023.
- Bottom-box responses increased from 8.4% in 2015 to 9.6% in 2023.
- Middle-box responses increased from 20.6% to 21.0% over the same period.

State-Level Performance

The analysis revealed variations in patient experience and survey response performance across states.

Average measure performance showed declines between 2015 and 2023 across the examined state-level measures.

Survey Response Analysis

- Total survey records: 43,219.
- Unique hospital facilities: 5,254.
- Unavailable survey responses: 5,772.
- Overall average response rate: 26.61%.
- Average response rate declined from 30.84% in 2015 to 22.74% in 2023.

These findings highlight changes in survey response patterns and hospital participation over the study period.
